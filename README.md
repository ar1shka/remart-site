# RemArt — сайт

Исходный код сайта строительной компании **РемАрт**.

Проект создан на **Vite + Vanilla JavaScript**.
Код хранится в GitHub, поэтому проект можно продолжать с любого компьютера.

---

## 1. Что нужно установить

Для работы с проектом нужны:

* **Visual Studio Code**
* **Node.js**
* **Git**
* **GitHub-аккаунт**

Проверить установку можно через терминал:

```cmd
node -v
npm -v
git --version
```

---

## 2. Как скачать проект на новый компьютер

Сначала установи все программы из предыдущего раздела.

После этого открой **Command Prompt** или терминал VS Code.

Перейди в папку, где будут храниться проекты:

```cmd
cd C:\Users\user\Projects
```

Если папки `Projects` ещё нет:

```cmd
mkdir Projects
cd Projects
```

Склонируй репозиторий:

```cmd
git clone https://github.com/ar1shka/remart-site.git
```

После этого появится папка:

```text
remart-site
```

Перейди в неё:

```cmd
cd remart-site
```

---

## 3. Установить зависимости проекта

После клонирования проекта выполни:

```cmd
npm install
```

Эта команда установит все зависимости, указанные в `package.json`.

Папка `node_modules` отдельно с GitHub не скачивается. Она создаётся автоматически после `npm install`.

---

## 4. Запустить сайт локально

Для запуска сайта используй:

```cmd
npm run dev -- --host 127.0.0.1
```

После запуска появится адрес:

```text
http://localhost:5173/
```

Открой его в браузере.

**Важно:** терминал с запущенным Vite нужно оставить открытым.
Если закрыть терминал или нажать `Ctrl + C`, локальный сервер остановится.

---

## 5. Если нужно продолжить работу с существующим проектом

Перед началом работы желательно получить последние изменения с GitHub:

```cmd
git pull
```

После этого запускай проект:

```cmd
npm run dev -- --host 127.0.0.1
```

---

## 6. Как сохранить свои изменения

После того как изменения в коде готовы, сначала проверь состояние Git:

```cmd
git status
```

Добавь изменения:

```cmd
git add .
```

Создай commit:

```cmd
git commit -m "Описание изменений"
```

Например:

```cmd
git commit -m "Create hero section"
```

Отправь изменения на GitHub:

```cmd
git push
```

После этого изменения появятся в репозитории GitHub.

---

## 7. Основной рабочий цикл

Когда работаешь на любом компьютере:

```text
1. git pull
2. Запустить сайт
3. Внести изменения
4. git status
5. git add .
6. git commit -m "Описание изменений"
7. git push
```

## 8. Если переходишь на другой компьютер

На новом компьютере:

```cmd

cd remart-site
npm install
npm run dev -- --host 127.0.0.1
```

После этого проект снова готов к работе.

## 10. Важно

### `node_modules`

Не нужно вручную копировать `node_modules` на другой компьютер.

После:

```cmd
npm install
```

она создастся автоматически.

### GitHub

GitHub хранит исходный код и историю изменений проекта.

Если компьютер сломается, проект можно восстановить через:

```cmd
git clone
```

### Перед началом работы на другом компьютере

Всегда полезно выполнить:

```cmd
git pull
```

чтобы получить последнюю версию проекта.

### После завершения работы

Не забывай:

```cmd
git add .
git commit -m "Описание изменений"
git push
```

```cmd

```

```cmd
git log --oneline
```

```cmd
git pull
```

Отправить изменения на GitHub:

```cmd
git push
```

---

## 12. Рабочая ветка

Основная ветка проекта:

```text
main
```

Все основные изменения сейчас сохраняются в `main`.

---

## 13. Если что-то пошло не так

Не удаляй проект и не переустанавливай Node.js или Git сразу.

Сначала посмотри:

```cmd
git status
```

и текст ошибки в терминале.

По ошибке можно определить, что именно произошло.
